<objective>
Build `StrategyDispatchStage` -- the generic, config-driven wrapper that turns D-07's per-rule-type `strategy` value into a genuine behavioral difference for ANY `StreamingStage` rule (completeness, validity-range, pattern, uniqueness, and every future rule type) -- and wire the four row-scoped rules (plans 08-04/08-07) into `StagingLoader._build_stages`, each one wrapped in this dispatcher, driven entirely by a dataset's `quality:` config block, appended after the existing normalizer stages so every value has already been normalized before a quality rule evaluates it.

Purpose: this is the moment VALID-01/02/03 stop being isolated, unit-tested rule classes and become real, config-addressable pipeline behavior with a REAL per-strategy outcome -- not just a `strategy` field that is stored but never consulted. 08-04's `CompletenessRule`/`ValidityRangeRule`/`PatternRule` and 08-07's `UniquenessRule` docstrings all explicitly punt strategy-based branching to this plan; `StrategyDispatchStage` is that landing point, built once and reused by every rule rather than duplicated per rule class. This is also the last piece before plan 08-11 can prove the full FAIL/QUARANTINE run-level outcome against a real dataset.
Output: `validate/strategy_dispatch.py` (new), `StagingLoader._build_stages`'s extension, `tests/unit/validate/test_strategy_dispatch.py` (VALID-03's own named proof in `08-VALIDATION.md`'s Per-Task Verification Map), and an integration test proving a configured rule genuinely rejects a bad row during a real staged load.

`StrategyDispatchStage`, implementing `StreamingStage` (`name` property returns `f"strategy_dispatch[{self._inner.name}]"`, so metrics/logs still trace back to the wrapped rule). `__init__(self, *, inner: StreamingStage, strategy: str, rule_id: str, rule_type: str) -> None`: validate `strategy in {"REJECT_RECORD", "QUARANTINE_RECORD", "WARN_AND_CONTINUE", "FAIL_FILE", "QUARANTINE_FILE"}` at construction, `raise ConfigurationError(f"unknown strategy {strategy!r}", context={"strategy": strategy, "rule_id": rule_id, "known": sorted([...])}) from None` otherwise; store all four args.

`apply(self, ctx, chunk) -> StageResult`: `result = self._inner.apply(ctx, chunk)`. If `not result.rejected`: `return result` unconditionally (no violation this chunk, no strategy has anything to do). Else, branch on `self._strategy`:

- `"FAIL_FILE"` / `"QUARANTINE_FILE"`: `raise QualityThresholdExceeded(f"strategy={self._strategy} rule {self._rule_id} rejected {len(result.rejected)} row(s) in this chunk -- escalating to run failure before publish", context={"rule_id": self._rule_id, "rule_type": self._rule_type, "strategy": self._strategy, "violation_count": len(result.rejected)})`.
