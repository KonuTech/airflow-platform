Close the one gap 07-VERIFICATION.md found after all 8 of Phase 7's original plans merged: `meta.v_customers_lineage` structurally SELECTs `dag_id`/`dag_run_id`/`task_id` (migration 0012, already live), but nothing anywhere in the codebase ever WRITES them -- confirmed live against a running production run (`run_id` 33613/33614, all three empty/NULL). `claim_ingestion_run()`'s UPDATE already lists `dag_id`/`dag_run_id`/`task_id`/`map_index`/`k8s_namespace` in `_INGESTION_RUN_UPDATABLE_FIELDS`, and `RunContext` already declares `dag_id`/`dag_run_id`/`task_id` fields -- but no write path was ever wired end to end, and Airflow's `KubernetesPodOperator` does not auto-inject `AIRFLOW_CTX_*` vars into launched pods (confirmed live: zero matches in a running `ingest` pod's env).

This plan wires the exact same mechanism plan 07-04 already proved out for `TRACEPARENT` (`TracingKubernetesPodOperator.build_pod_request_obj()`, an operator-subclass override running at task-execution time, not DAG-parse time) to also carry Airflow's own task identity across the pod boundary, and threads it through the same `RunContext` -> `run_ingest()` -> `claim_ingestion_run()` chain plan 07-05 already proved out for `trace_id`/`span_id`.

Purpose: Close ROADMAP Phase 7 Success Criterion 2 / OBS-07's full literal wording -- "one SQL query returns, for any warehouse row, its ... DAG/run/task ID ..." -- for real, live, Airflow-triggered production runs, not merely for a hand-constructed offline fixture.

Output: A `RunContext`/`claim_ingestion_run()`/`meta.ingestion_runs` chain that persists Airflow's DAG/run/task/map-index identity and the pod's own Kubernetes namespace; a `TracingKubernetesPodOperator` that injects that identity into every `ingest` pod's environment; a flipped `tests/integration/test_lineage_view.py` that proves the round-trip; and a new live-cluster E2E test proving a genuinely live, Airflow-triggered row shows non-NULL `dag_id`/`dag_run_id`/`task_id` in `meta.v_customers_lineage` itself.

def build_pod_request_obj(self, context: object = None) -> k8s.V1Pod:
    pod = super().build_pod_request_obj(context)
    carrier: dict[str, str] = {}
    propagate.inject(carrier)
    if "traceparent" in carrier:
        pod.spec.containers[0].env.append(
            k8s.V1EnvVar(name="TRACEPARENT", value=carrier["traceparent"]),
        )
    return pod
