<interfaces>
`dbt/macros/dedup_audit_post_hook.sql` (verified this session, full 178-line read) is the direct,
load-bearing template. Its three header-documented lessons, ALL apply identically here:
(1) accept `dataset_name` as a plain string, resolve `dataset_id` via
`meta.dataset_id_for_name(text)` (a `SECURITY DEFINER` function, migration 0028) INSIDE the macro's
own INSERT — never a direct `SELECT` against `meta.datasets` (fails `dbt_app`'s least-privilege
grant test). (2) accept `source_schema`/`source_identifier`/`target_schema`/`target_identifier` as
plain STRINGS, never `{{ source(...) }}`/`{{ this }}` Relation objects as macro arguments — verified
unreliable across `post_hook`'s two-pass Jinja evaluation. (3) derive any prior-state value from the
audit table's OWN history (`coalesce(max(...), 0)`), never from a `run_query()` value captured into
a `post_hook` config string.

`dbt/models/silver/silver_customers.sql` (verified this session, full read): the model's
`{% set post_hook_sql %}{{ dedup_audit_post_hook(dataset_name='customers', ...) }}{% endset %}`
block, captured EAGERLY in the model's own primary render pass (the file's own docstring explains
why — a deferred `{{ ... }}` render is unreliable for exactly this kind of macro call), then handed
to `config(..., post_hook=post_hook_sql)`. This plan extends the SAME captured block — appends a
second macro call to the SAME `post_hook_sql` string — rather than introducing a second
`config(post_hook=[...])` list, keeping the model's existing single-string shape unchanged.

`migrations/versions/0032_meta_reconciliation_results.py` (plan 09-02) already grants `dbt_app`
`SELECT, INSERT` on `meta.reconciliation_results` and needs no re-grant of `USAGE ON SCHEMA meta`
(already granted by migrations 0021/0024).

`dbt/models/silver/silver_customers.yml` (verified this session, full read): the existing
`contract: {enforced: true}` + `data_tests: [not_null, unique]` shape — this plan adds a
model-level `tests:` entry with `config: {severity: warn}`, additive, never replacing the existing
contract/tests.
</interfaces>
