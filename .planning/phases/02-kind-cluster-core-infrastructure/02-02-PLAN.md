<objective>
Turn the tracer's manual proof into two permanent mechanisms: a fail-closed host preflight that
refuses to build a cluster on a machine that cannot host one, and a re-runnable live-cluster test
suite that is the regression net for every later phase that edits a values file.

Purpose: Phase 1's discovery was that four gates passed on broken input. A check that reports
without blocking is a check people scroll past during a ten-minute build, and a test directory that
no target names is silently uncollected (WINDOWS #8). Both defects are closed here, before any
component depends on them.

Output: `make doctor`, `make cluster-verify`, `make cluster-rebuild`, the
`tests/e2e/cluster/` harness, and the three policy tests that prove each new gate actually fails.
</objective>

<user_story>
**As a** platform engineer,
**I want to** be told exactly why my machine cannot host the cluster before ten minutes of image
pulls, and to re-prove the whole environment with one command after any change,
**so that** a broken host is a two-second message with a fix command rather than a confusing
failure deep inside a chart install.
</user_story>
