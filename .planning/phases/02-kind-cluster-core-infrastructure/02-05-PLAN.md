    pin both and select per chart. State that the fallback has **no surviving trigger in this phase**

    Decision Outcome and Consequences must record the CLI contract changes that this repository's
    scripts depend on, because they are the reason a copied Helm-3 command line silently does the
    wrong thing: `--atomic` no longer exists and its nearest equivalent is `--rollback-on-failure`;
    `--wait` is a strategy whose default when the flag is omitted is `hookOnly`, so a workload wait
    must be requested explicitly; server-side apply is the default; `--force` became
    `--force-replace`; `--dry-run` takes a string; and `helm status --show-resources` is gone, so
    any script parsing it breaks. Name `scripts/helm-install.sh` as the single place the wait
    strategy is expressed, and cite the measured consequence of getting it wrong: an operator
    install returning in 1.0 s with the operator not yet serving.

    Migration trigger: a pinned chart failing to render or install under Helm 4, or an upstream
    chart declaring a Helm-4 incompatibility.
