<objective>
Wire the five independently-built detectors and the compression layer into one real, live pipeline
stage: `CsvSource.inspect()`, aggregating filename/encoding/dialect/header/type-inference findings
into a `CsvProfile`, and `CsvSource.open()`, now actually constructing its `io.TextIOWrapper`/
`csv.reader` from whatever `inspect()` detected — replacing Phase 3's `03-CONTEXT.md` D-01 hardcoded
UTF-8/comma/header-row-0 shape for good. This is the convergence point ROADMAP's "parallelize the five
detectors as independent concurrent plans" guidance always implied would exist: each detector proved
itself correct in isolation (Wave 2); this plan is the thin, mechanical step that makes them real.

Purpose: without this plan, every detector built in Wave 2 remains an unintegrated unit — correct, but
never actually consulted by a real ingestion run. `Source.inspect()`'s Protocol shape was deliberately
left absent in Phase 3 (`dataplat.sources.protocol`'s own module docstring names this exact moment:
"Phase 6 adds inspect() plus the two attributes once their types exist").
Output: `CsvProfile` (in `dataplat`, holding only primitive/plain-data fields so `dataplat` never
imports `csv_processor` — the import-linter contract stays green), `Source.inspect()` added to the
Protocol, and `CsvSource.inspect()`/`open()` as the first real implementation.
</objective>

from __future__ import annotations
from dataclasses import dataclass
from typing import Mapping

@dataclass(frozen=True, slots=True)
class CsvProfile:
    """Everything Source.open()/chunking need, assembled once by Source.inspect() (Pattern 1)."""
    encoding: str
    encoding_confidence: float
    encoding_source: str          # "contract" | "bom" | "detected" | "undetermined"
    delimiter: str | None
    quotechar: str
    dialect_declined: bool
    header_row_index: int | None
    header: tuple[str, ...]
    preamble_row_count: int
    footer_row_count: int
    max_field_bytes: int
    compression: str | None       # None | "gzip" | "zip"
    filename_facets: Mapping[str, object]

# packages/dataplat/src/dataplat/sources/protocol.py -- Source gains, alongside the existing open():
class Source(Protocol):
    def open(self, ctx: PipelineContext) -> AbstractContextManager[RecordStream]: ...
    def inspect(self, ctx: PipelineContext) -> CsvProfile: ...   # NEW this task
