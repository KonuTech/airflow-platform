<objective>
Build CSV-01's filename mask parser as a self-contained, corpus-independent pure function: a
strptime-style token mask (`{dataset}_{country}_{business_date:%Y%m%d}[_{seq:03d}].csv`) compiles to
an anchored regex, and matching a real filename against it either returns every declared facet as a
typed value, or raises a named diagnostic when the filename does not match the mask at all — never a
partial match with facets silently left null.

Purpose: this is one of the five detectors ROADMAP.md's Phase 6 plan guidance names as "the single
best parallelization opportunity in the project" — it shares no file, no mutable state, and no
functional dependency with the other four detector plans in this wave. `customers` (the platform's
only real dataset) deliberately does not use a filename mask (D-10), so this capability's evidence is
entirely this plan's own corpus-independent unit tests, not a live pipeline run — matching CONTEXT.md's
explicit instruction not to treat `customers.yaml` staying unchanged on this axis as a gap.
Output: `compile_mask`/`match_filename`, wired to raise `FilenameParsingError` (from 06-02) with the
`"filename-does-not-match-mask"` diagnostic code (from 06-02) on a non-match.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Object-store key / uploaded filename → `parse_filename` | The filename string originates from an object key in the `raw` bucket — attacker-influenceable by anyone who can upload to a configured source path |
| `configs/datasets/*.yaml` `filename.mask` → compiled regex | The mask string itself is operator-authored config, not attacker-influenceable |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-03 | Denial of Service | `compile_mask`'s token→regex expansion | mitigate | Every generated character class is fixed-width and bounded (`\d{4}`, `\d{2}`, a bounded `[^_./]+` segment) — never `.*` or a nested/backtracking quantifier, so an attacker-controlled filename cannot trigger catastrophic regex backtracking (ReDoS) regardless of length |
| T-06-09 | Tampering | A crafted filename engineered to match a mask with attacker-chosen facet values | accept | Extracted facets (dataset/country/business_date/seq) are recorded as file/lineage metadata, never used to construct SQL or shell commands, and `business_date`'s only sanctioned use is D-11's documented fallback role — low-value target |
</threat_model>
