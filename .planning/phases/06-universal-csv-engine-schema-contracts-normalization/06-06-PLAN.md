<objective>
Build CSV-07/CSV-08's header/metadata/footer detector: for each candidate row index, score it on
(a) all fields non-empty, (b) all fields non-numeric, (c) field count equal to the modal field count
of the following rows, (d) value uniqueness — pick the first row above threshold as the header;
everything before it is metadata preamble; trailing rows whose field count differs from the modal
count (or whose first field matches a footer pattern) are the footer. Reject exact and case-variant
duplicate header names outright — never silently rename or last-wins.

Purpose: one of the five independently-parallel detector plans. This is STACK.md's own
`detector/header.py` design, now made real. Ten corpus fixtures (11, 12, 13, 18, 19, 48, 49, 63, 64,
plus the case-insensitive-collision pair 14/48) exist specifically to pin this detector's edge cases —
this plan's job is to make every one of them pass against its own `expect:` block, not to invent new
behavior beyond what they declare.
Output: `detect_header`, corpus-fixture-parametrized, producing a result the streaming reader and
schema-contract validation both consume.
</objective>
