<objective>
Build CSV-10's boolean/NULL half and CSV-12's Unicode NFC normalizer, both as `StreamingStage`s: exact
(never substring) matching against contract-declared NULL tokens and locale-specific boolean token
maps, rejecting any unmapped boolean value rather than defaulting it; and an unconditional,
non-configurable NFC normalization pass that is D-15's fixed platform rule — every string value, for
every dataset, before any hash computation ever runs.

Purpose: two of the independently-parallel normalizer plans, grouped into one plan because both are
individually small relative to dates/numeric (a token lookup and a single `unicodedata.normalize`
call). Corpus fixtures 24 (null tokens, with the deliberate `"NULL Industries"` trap), 60 (boolean
tokens, with the `O`-means-French-`Oui` trap), 42 (invisible zero-width/bidi characters) and 44 (NFC
vs. NFD) each pin exactly the failure mode this plan must not reproduce.
Output: `NullTokenNormalizer`, `BooleanNormalizer`, `UnicodeNormalizer` — all `StreamingStage`s, unit
tested against every CSV-10-boolean/null and CSV-12-tagged corpus fixture.
</objective>
