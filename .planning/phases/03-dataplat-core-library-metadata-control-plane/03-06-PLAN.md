<objective>
Define `PipelineContext` — the one object that composes every subsystem built in Waves 1-2 — and
the `Source`/`RecordStream`, `StreamingStage`/`BarrierStage`, `Publisher` protocols built against
it. Implement the one concrete piece of pipeline logic this phase needs: a generic
sequencing/checkpoint loop plus a real `StreamingStage` example proving QUAL-03's errors-as-values
mechanism. Record the composition seam itself as ADR-0008.

Purpose: `PipelineContext` cannot exist before `DatasetConfig` (plan 03-04), `MetadataRepository`
and `ObjectStore` (plan 03-05) do — it is a genuine, not artificial, Wave-3 dependency. Every
other protocol in this plan (`Source`, `Publisher`) takes `PipelineContext` as a parameter, so
they inherit the same wave placement. This is the phase's last purely-contractual plan; csv_processor
(plan 03-08) is the first real `Source` consumer.
