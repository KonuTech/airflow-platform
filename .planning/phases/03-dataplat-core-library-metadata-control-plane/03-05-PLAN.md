<objective>
Build the two infrastructure-facing subsystems that make the `meta` schema (plan 03-02) and MinIO
actually usable from Python: `ObjectStore` (the corrected, adapter-free StreamingBody-to-text-
stream bridge) and `MetadataRepository` (typed CRUD over the five slice tables). Both are proven
against real testcontainers infrastructure, not mocks.

Purpose: META-01's "creates the whole meta schema" claim is hollow if nothing can write to it
through typed code — this plan is the proof that the schema plan 03-02 created is not just
DDL-valid but genuinely usable. It also closes out 03-RESEARCH.md's corrected finding: the
`io.RawIOBase` adapter PITFALLS.md E1 originally called for is unnecessary against the pinned
boto3 version, and this plan is where that correction becomes committed, tested code. Finally,
this plan closes the one remaining gap in SEC-15 / ROADMAP success criterion 4: it proves a live
connection pool built from `resolve_secret()`'s output (plan 03-03), not a hardcoded DSN, executes
a real query — the resolver and the pool factory are each well-tested in isolation elsewhere in
this phase, but only here are they proven wired together end to end.

Output: `dataplat/storage/objectstore.py`, `dataplat/metadata/{repository,postgres}.py`, and two
integration tests proving both against testcontainers MinIO and Postgres — the second of which
also proves the `resolve_secret()`-to-`create_pool()` wiring.
</objective>
