```python
def chunked_records(
    text_stream: io.TextIOWrapper, *, dialect: csv.Dialect | type[csv.Dialect],
    chunk_size: int, field_size_limit: int,
) -> Iterator[tuple[int, list[tuple[str, ...]]]]:
    csv.field_size_limit(field_size_limit)
    reader = csv.reader(text_stream, dialect=dialect)
    header = next(reader)                      # D-01: header at row 0, hardcoded
    ordinal = 0
    for batch in itertools.batched(reader, chunk_size):
        yield ordinal, list(batch)              # checkpoint value: a RECORD ORDINAL
        ordinal += len(batch)
```

`RecordStream.chunks(self, *, start_ordinal: int | None = None) -> Iterator[RecordChunk]` and
`Source.open(self, ctx: PipelineContext) -> AbstractContextManager[RecordStream]` — the exact

`RecordChunk(rows: tuple[tuple[str, ...], ...], first_ordinal: int, expected_field_count: int)`
from `dataplat.models.record` (plan 03-01) — `expected_field_count` is set from `len(header)`.

`open_text_stream(response_body, *, encoding, newline="", errors="strict") -> io.TextIOWrapper`
