## Decisions Made

- ADR-0010's Decision Outcome is **C** (dbt owns bronze→silver only): the load-bearing reasons
  are PG BUG #18279 (dbt's `merge` strategy compiles to real PostgreSQL `MERGE`, the same
  concurrency hazard `MergePublisher` avoids via `INSERT ... ON CONFLICT`) and META-03 (dbt's
  own per-model transactions cannot participate in the single-transaction data+watermark+status
  commit this project already proved live at 10M-row scale).
- Narrowed rather than deleted the PROJECT.md Key Decisions row and REQUIREMENTS.md Out of Scope
  row, per this project's own additive/superseding documentation convention (mirroring
  `discovery.py`'s idempotency-key-formula evolution discipline cited in the plan).
