<objective>
Build the third single-purpose Docker image this platform needs: a dbt-core 1.12.2 + dbt-postgres
1.11.0 image (RESEARCH.md's pinned, PyPI-verified versions) containing no `dataplat`,
`csv_processor` or `apache-airflow` (ADR-0004's two-image discipline extended to three, per
RESEARCH.md's Anti-Patterns table), plus a standalone secret-resolution script that gives this
image the SAME `vault://mount/path#field` credential-delivery pattern the rest of the platform
uses — without coupling it to the `dataplat` package (RESEARCH.md Architecture Pattern 4).

and the concrete mechanism that makes dbt-native `incremental_strategy`/`unique_key` config the
real strategy interface DEDUP-03 requires ("never `SELECT DISTINCT`") — the image is what
executes that interface.
Output: `docker/dbt/Dockerfile`, `docker/dbt/resolve_secrets.py`, a `make image-dbt` target, and an
integration test proving the image builds and runs correctly.
