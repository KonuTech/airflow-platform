## Sampling Rate

- **After every task commit:** Run `pytest tests/unit -q`
- **After every plan wave:** Run `pytest tests/ -q -m "not cluster and not manifests"`
- **Before `/gsd:verify-work`:** Full suite must be green, including the new `dbt`-marked integration
  tests
- **Max feedback latency:** 60s
