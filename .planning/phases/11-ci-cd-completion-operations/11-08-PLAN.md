## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-19 | Tampering (data loss) | Deletion calls inside this DAG | mitigate | gated per-dataset, per-layer on `RetentionConfig.enforce`, which defaults `false` at the Pydantic model level (plan 11-07); Task 2's dagtest proves zero deletion calls occur in the default configuration |
| T-11-20 | Repudiation | A deletion with no audit trail | mitigate | every evaluation logs the full structured report (candidate counts, would-delete/deleted counts, oldest/newest) via `dataplat.observability.logging` before any delete is attempted |
| T-11-21 | Denial of Service | Raw layer accidentally targeted | mitigate | `raw_days` defaults `None` (indefinite) at the config layer (plan 11-07), and this DAG's own raw-layer query path is additionally backstopped by the MinIO IAM deny-delete policy (D-40) — even a misconfigured `enforce: true` + a numeric `raw_days` could not delete from `raw` through the `etl-app` credential this DAG's tasks use |
| T-11-SC | Tampering | npm/pip/cargo installs | N/A | no new third-party dependency is introduced |
