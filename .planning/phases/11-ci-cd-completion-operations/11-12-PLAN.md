<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `rebuild-from-raw` -> the entire analytical warehouse | The single most destructive operation in the whole platform; a bug here is total data loss, recoverable only from raw |
| Pre-drop snapshot storage (MinIO `metadata` bucket) | Must itself survive the operation it is meant to validate |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-31 | Tampering (catastrophic data loss) | `DROP SCHEMA ... CASCADE` targeting the wrong database | mitigate | the script connects only via the analytics CNPG cluster's own discovered superuser credential (mirroring `migrate-analytics`'s existing, already-guarded pattern) and hard-names exactly `staging`/`silver`/`normalized`/`meta` — it never resolves a connection string that could point at the Airflow metadata database (a structurally separate CNPG cluster, INFRA-04) |
| T-11-32 | Tampering | MinIO wipe accidentally including `raw` or `metadata` | mitigate | the wipe function's bucket list is a hard-coded, reviewed three-item tuple; Task 1's own acceptance criteria grep-check this explicitly |
| T-11-33 | Repudiation | A rebuild whose pre-drop snapshot is lost along with the drop | mitigate | the snapshot is written to the `metadata` bucket specifically because it is NEVER wiped by this same operation (unlike `validated`/`processed`/`quarantine`) or dropped (it is object storage, not a PostgreSQL schema) |
| T-11-34 | Denial of Service | A rebuild triggered against a live, actively-serving production-like environment | accept | this project's stated context is local/dev; the Make target's own help text and this plan's threat model both name this as the disaster-recovery / CI-capstone use case, not a routine operation — no additional confirmation gate is added, matching this project's existing `cluster-rebuild`/`vault-bootstrap` precedent of trusting the operator who runs a Make target by name |
| T-11-SC | Tampering | npm/pip/cargo installs | N/A | no new third-party dependency is introduced |
</threat_model>
