<objective>
Restore SEC-13's claim — "development secrets are... reproducible when rebuilding the local environment from scratch" — from documented-but-false to genuinely true, by fixing the one root cause both 05-VERIFICATION.md and 05-REVIEW.md independently found: `scripts/vault-bootstrap.py`'s `_ensure_etl_secrets()`/`_ensure_airflow_secrets()` source their Vault KV values from three Kubernetes Secrets (`csv-processor-db`, `csv-processor-s3`, `airflow-minio-connection`) that this same phase's own plans (05-02, 05-03) already deleted, along with their sole creator `scripts/etl-secrets.sh`. This plan also fixes the same-root-cause CR-02 defect (`_ensure_policy()` never re-applies a drifted policy body) while the file is already open for this reason, per the gap's own "cheap alongside" instruction.

Purpose: Phase 5 verified 12/13 must-haves (05-VERIFICATION.md). This is the one blocking gap. Without this fix, a genuinely fresh cluster rebuild leaves Vault structurally bootstrapped (mounts, auth method, policies, roles, audit device all succeed) but with **zero credential values ever written** — every workload's `resolve_secret("vault://...")` and Airflow's `VaultBackend` lookup then fail, with no documented recovery path, directly contradicting SEC-01's "Vault is the ONLY source of runtime credentials" the moment the cluster is ever actually rebuilt — which, on this project's WSL2 environment, is a realistic every-morning event, not an edge case.

Output: A corrected `scripts/vault-bootstrap.py`; a new, fully offline unit-test regression guard (`tests/unit/test_vault_bootstrap.py`) that catches this class of regression without needing a live cluster; one completed live-cluster proof against the real kind cluster (via a scoped Vault-release-and-PVC reinstall, not a full cluster teardown — see Task 2 for the exact, deliberately narrow blast radius); and documentation (`docs/secrets-architecture.md`, `05-VALIDATION.md`) that accurately cites what was actually proven, per this project's own stated citation-discipline bar.
</objective>
